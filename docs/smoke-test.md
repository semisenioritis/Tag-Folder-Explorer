# Smoke test checklist

Run in a copy of the test vault after every Block 1 task. Record pass/fail per item.

- [ ] Open the explorer from the ribbon icon.
- [ ] Open the explorer from the command palette.
- [ ] Navigate into folders, then use back and forward.
- [ ] Drag a file onto a folder inside the explorer (internal drop).
- [ ] Drag a file from Obsidian's file explorer into a folder (external drop).
- [ ] Pin and unpin a file.
- [ ] Pin and unpin a folder.
- [ ] Set a legend color on a file and on a folder.
- [ ] Rename a file.
- [ ] Rename a folder.
- [ ] Delete a file.
- [ ] Delete a folder.
- [ ] Edit a folder description.
- [ ] Edit a file description.
- [ ] Create a file.
- [ ] Create a folder (and confirm an empty folder survives a reload).
- [ ] Restart Obsidian with an explorer tab open. (Known baseline failure until Block 2 task 01.)
- [ ] Open two explorer tabs on different folders and confirm both stay in sync.
